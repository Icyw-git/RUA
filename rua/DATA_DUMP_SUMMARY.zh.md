# Data Dump 功能概览

Data dump 将运行时保存的画面、状态、动作和已有决策记录整理为可追溯的数据，并按动作片段的物理证据筛选 WLA 训练起点。推荐入口和命令见 [DATA_DUMP.zh.md](DATA_DUMP.zh.md)。

## 推荐流程

```text
保存完整 episode → 回放并核对原动作 → 四类质量标签
                → 筛选连续八步动作的训练起点 → 导出完整 LeRobot episode
```

运行时自动保存原始记录；episode 完成后，操作者启动离线质量流程。回放不请求模型，会在独立仿真环境中执行已记录动作。回放状态仅用于离线判断，不输入原控制器。

| 步骤 | 当前行为 |
| --- | --- |
| 回放与核对 | 检查末端位置与官方成功结果是否和原运行一致，收集物体、接触、关节与目标条件证据。 |
| 分类 | `nominal` 为有后续进展支持的动作；`recovery` 为有错误和后续纠正证据的动作；其余为 `error` 或 `uncertain`。 |
| 筛选 | 仅选择连续八步都属于同一类、证据确认且完整的 `nominal/recovery` 动作，并要求真实未来帧存在。 |
| 导出 | 保留获选轨迹的完整 episode；训练起点清单决定加载器实际读取哪些窗口，保留原始历史图。 |

最终失败的轨迹也可能贡献局部可用片段。`verified` 不代表逐步确认了最优动作或训练收益；持续拿着错误物体的动作和缺少证据的动作不能作为正面监督。

## 主要产物

| 产物 | 用途 |
| --- | --- |
| `oracle/` | 回放得到的逐步物理证据。 |
| `quality-labels.jsonl` | 每段动作的质量标签、来源和证据版本。 |
| `behavior-signals.jsonl` | 慢速、绕行、重复夹爪周期的辅助排查线索，不自动剔除训练样本。 |
| `review-starts.jsonl` | 辅助线索覆盖的已导出训练起点。 |
| `dump/feedback.jsonl` | 每个来源的处理结果、拒绝原因和最终训练起点数量。 |
| `dump/trace.jsonl` | 可读的原始事件、已有 Agent 决策和请求记录；不伪造损坏内容。 |
| `dump/dump-manifest.json` | 导出结果及其与原始 episode 的对应关系。 |
| `dump/rua_lerobot/` | 双视角视频、状态、动作、任务文字和 `meta/quality-starts.jsonl` 训练起点清单。 |
| `summary.json` | 整批来源数、预处理失败数、拒绝数及入选数量。 |

## 批量失败如何处理

单条文件缺失、格式错误、回放不一致或分类输入错误会记入现有 feedback，其余来源继续处理。被拒绝的来源，其最终训练起点数和两类起点数均为零。全部拒绝时仍有 feedback 和零计数 manifest，不生成空 LeRobot 数据集。

退出码 `0` 表示正常完成（允许没有合格样本）；`2` 表示有来源预处理失败，但其余来源已处理。程序错误、依赖故障及系统级故障仍会中止，不作为普通数据拒绝处理。发生全局故障时应使用新的输出目录重跑，不把未完成目录当成可用数据集。

## 使用边界

- 当前自动标签覆盖 LIBERO 的抓取放置与抽屉目标，其他任务保持待定。
- 当前训练格式需要前视、腕视、8 维状态、7 维动作和真实未来帧。初始化动作不进入训练。
- 基础导出和人工复核是兼容入口，不必串联在推荐质量流程后运行；基础模式仍以整条成功为准。
- 本阶段 Pro 数据用于验证 dump 和筛选功能；训练收益与独立评测属于后续实验。
- Agent 决策记录继续保留，但本模块尚不生成 Agent 训练集。暂不提供自动调度、增量追加或断点续跑。
